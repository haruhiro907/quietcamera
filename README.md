# Quiet Camera

iPhone 17 / iOS 26 の標準カメラを設計基準にした、Android 専用・静止画専用のカメラアプリ。
対象端末は OPPO Reno7 A（個人利用・APK 直接インストール、ストア配布なし）。

詳細設計書: [docs/QuietCamera_DesignDoc.md](docs/QuietCamera_DesignDoc.md)

## 技術構成

- Kotlin / Jetpack Compose / CameraX
- minSdk 30、compileSdk / targetSdk 36
- バージョンは `gradle/libs.versions.toml` で一元管理（AGP 9.5.1 / Kotlin 2.4.21 / CameraX 1.6.2 / Compose BOM 2026.09.00）

## Phase 0 の実機確認手順

1. APK を Reno7 A にインストールして起動する
2. CAMERA 権限を許可する
3. 画面に表示される調査結果を確認する（「結果を共有」「コピー」で取り出し可能）
4. 「無音で撮影テスト」を押し、**システム撮影音が鳴るか**を耳で確認する
   （写真は `DCIM/QuietCamera` に `QC_PHASE0_...` として保存される）
5. 「振動テスト」3ボタンを押し、弱いクリックとして感じられるか確認する
6. ロック画面起動の確認（設計書 2.3 / 4.8）
   1. Reno7 A のクイック起動に Quiet Camera を割り当てる
   2. 画面をロックした状態でクイック起動し、**解除を求められずに画面が出るか**を確認する
      （画面上部に「起動状態: ロック中」と「起動→画面表示」の時間が表示される）
   3. ロック中のまま「無音で撮影テスト」ができるか確認する
   4. ロック中に電源ボタンで画面を消し、再点灯時にアプリが終了しているか確認する
   5. 暗証番号・指紋認証を設定した状態でも同じか確認する

※ Phase 0 の実機確認は完了（結果は docs/phase0-results.md）。この手順は記録用に残す。

## Phase 1 の実機確認手順

1. APK をインストールして起動し、背面カメラのプレビューが 4:3 で表示されるか確認する
2. 上部バーの「プレビュー表示まで」の時間が 1500ms 以内か確認する
3. 再点灯時の表示確認（Phase 0 で見つかった不具合の修正確認）
   1. アプリを開いたまま電源ボタンで画面を消す
   2. 再点灯したとき、通常どおりロック画面だけが表示され、アプリが重なって出ないか確認する
4. クイック起動（指紋解除→スワイプ）からもプレビューが出るか確認する

## Phase 2 の実機確認手順

1. APK をインストールして起動し、シャッター（下部の白い丸）を押す
2. 上部に「保存しました」と出て、標準の写真アプリに写真が表示されるか確認する
   （保存先は `DCIM/QuietCamera`、ファイル名は `IMG_日時`）
3. **向きの確認**: 端末を横向きにして撮影し、保存された写真の向きが正しいか確認する
4. 連続して数枚撮れるか確認する（同秒に複数枚撮ると `_001` の連番が付く）
5. 撮影のたびにプレビューが一瞬暗くなるか確認する

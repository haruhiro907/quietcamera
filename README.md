# Quiet Camera

iPhone 17 / iOS 26 の標準カメラを設計基準にした、Android 専用・静止画専用のカメラアプリ。
対象端末は OPPO Reno7 A（個人利用・APK 直接インストール、ストア配布なし）。

詳細設計書: [docs/QuietCamera_DesignDoc.md](docs/QuietCamera_DesignDoc.md)

## 技術構成

- Kotlin / Jetpack Compose / CameraX
- minSdk 30、compileSdk / targetSdk 36
- バージョンは `gradle/libs.versions.toml` で一元管理（AGP 9.5.1 / Kotlin 2.4.21 / CameraX 1.6.2 / Compose BOM 2026.09.00）

## Phase 0 の実機確認手順

1. APK を Reno7 A にインストールして起動する
2. CAMERA 権限を許可する
3. 画面に表示される調査結果を確認する（「結果を共有」「コピー」で取り出し可能）
4. 「無音で撮影テスト」を押し、**システム撮影音が鳴るか**を耳で確認する
   （写真は `DCIM/QuietCamera` に `QC_PHASE0_...` として保存される）
5. 「振動テスト」3ボタンを押し、弱いクリックとして感じられるか確認する
6. ロック画面起動の確認（設計書 2.3 / 4.8）
   1. Reno7 A のクイック起動に Quiet Camera を割り当てる
   2. 画面をロックした状態でクイック起動し、**解除を求められずに画面が出るか**を確認する
      （画面上部に「起動状態: ロック中」と「起動→画面表示」の時間が表示される）
   3. ロック中のまま「無音で撮影テスト」ができるか確認する
   4. ロック中に電源ボタンで画面を消し、再点灯時にアプリが終了しているか確認する
   5. 暗証番号・指紋認証を設定した状態でも同じか確認する

※ Phase 0 の実機確認は完了（結果は docs/phase0-results.md）。この手順は記録用に残す。

## Phase 1 の実機確認手順

1. APK をインストールして起動し、背面カメラのプレビューが 4:3 で表示されるか確認する
2. 上部バーの「プレビュー表示まで」の時間が 1500ms 以内か確認する
3. 再点灯時の表示確認（Phase 0 で見つかった不具合の修正確認）
   1. アプリを開いたまま電源ボタンで画面を消す
   2. 再点灯したとき、通常どおりロック画面だけが表示され、アプリが重なって出ないか確認する
4. クイック起動（指紋解除→スワイプ）からもプレビューが出るか確認する

## Phase 2 の実機確認手順

1. APK をインストールして起動し、シャッター（下部の白い丸）を押す
2. 上部に「保存しました」と出て、標準の写真アプリに写真が表示されるか確認する
   （保存先は `DCIM/QuietCamera`、ファイル名は `IMG_日時`）
3. **向きの確認**: 端末を横向きにして撮影し、保存された写真の向きが正しいか確認する
4. 連続して数枚撮れるか確認する（同秒に複数枚撮ると `_001` の連番が付く）
5. 撮影のたびにプレビューが一瞬暗くなるか確認する

## Phase 3 の実機確認手順（Version 0.1）

1. シャッター: 押すと内側の円だけが少し縮み、**指を離した瞬間に撮影**されるか。
   撮影後に左下のサムネイルが新しい写真に変わるか
2. サムネイルをタップすると標準の写真アプリで写真が開くか
3. 右下の切替ボタンで前面カメラに切り替わるか。前面のプレビューが鏡表示か、
   保存した写真が鏡像になっていないか（文字入りのものを撮ると判別しやすい）
4. 端末を横向きにすると、サムネイルと切替アイコンだけが回転して正向きに見えるか
5. 最下部に PHOTO と表示されているか

## Phase 4 の実機確認手順（Version 0.2）

1. ズーム: プレビュー下のピルに 1 / 2 / 6 と表示され、タップで滑らかにズームするか。
   （Phase 0 の実測で minZoomRatio = 1.0 のため、この端末では .6 ボタンは出ないのが正しい挙動）
   ピンチでもズームできるか。ピル長押しでスライダーが出て連続ズームできるか
2. フォーカス: プレビューをタップすると黄色い枠が出て、その場所にピントと明るさが合うか。
   タップ後に上下ドラッグで明るさが変わり、枠横の太陽が動くか
3. AE/AF ロック: 長押しで「AE/AF ロック」と表示され、カメラを動かしても明るさが
   変わらないか。再度タップで解除されるか
4. フラッシュ: 上部バーの稲妻から AUTO / ON / OFF を切り替えられるか。
   背面 ON で暗所撮影時に光るか。前面カメラで ON にして暗所で撮ると画面が白く光るか
5. タイマー: 上部バーの時計ボタンをタップするごとに OFF → 3s → 10s と切り替わるか。
   3s にしてシャッターを押すと大きな数字のカウントダウン（1 秒ごとの弱い振動）後に
   撮影されるか。カウント中のシャッター再タップでキャンセルできるか

※ 初回確認（2026-11-13）: 2〜5 は OK。1 のピンチが効かない（タップフォーカス・
露出ドラッグと競合）＋ピル長押しでダイヤルが出ない不具合を v7 で修正。
ジェスチャ判定を単一ハンドラに統合し、ピルの押下処理も一括判定に変更した。
v7 では 1（ピンチとダイヤル）のみ再確認する。

※ v7 再確認（2026-11-13）: ダイヤルは OK。ピンチは概ね効くが、太陽マーク
（露出表示）が出ているときにズームしづらい → v8 でプレビューのジェスチャ判定を
指の本数で決める単一ハンドラに作り替えた（2 本指は常にピンチのみ）。
v8 では「太陽表示中のピンチ」のみ再確認する。

## Phase 5 の実機確認手順（Version 0.3）

前提： Phase 4 までの動作（撮影・ズーム・フォーカス・フラッシュ・タイマー）が維持されていること。

1. **シャッター音と触覚**: 撮影すると、小さな柔らかいクリック音と弱い振動が
   あること。音が大きすぎないか、耳障りでないか。
2. **設定パネル**: 上部中央のシェブロン（︿）をタップすると、ガラス風パネルが
   スプリングで開くこと。もう一度タップで閉じること。
3. **アスペクト比**: パネルで 16:9 にするとプレビューが縦に広がり、保存写真も
   16:9 になること。1:1 ではプレビューが正方形になり、保存写真も正方形に
   なること。4:3 に戻せること。
4. **グリッド**: ON にするとプレビューに 3×3 の線が出ること。
5. **水準器**: ON にすると中央に水平線が出て、端末を傾けると線が水平を保とうと
   し、水平（±1° 以内）で黄色くなること。
6. **画質**: 「高画質」に切り替えて撮影でき、写真が保存されること（体感で
   撮影間隔が少し長くなってもよい）。
7. **設定の保存**: フラッシュ・タイマー・グリッド等を変更してアプリを再起動し、
   設定が保持されていること。
8. **シャッター設定**: パネルで「シャッター音 OFF」にすると音だけ消えること。
   「触覚フィードバック OFF」で振動だけ消えること。音量スライダーで音の大きさが
   変わること。マナーモードでは既定で音が鳴らないこと。
9. **アプリ設定（歯車）**: 起動時のカメラを「前面」にして再起動すると前面で
   起動すること。「前面カメラのミラー保存 ON」で前面撮影の保存が鏡像になること。
   「設定を初期化」で全設定が既定値に戻ること。

※ 既知の割り切り: プレビュー映像そのもののブラーは SurfaceView のため効かず、
パネルは暗色半透明＋白 tint で代替している（設計書 3.5 のフォールバック）。
ガラス感の調整は確認結果を聞いてから行う。

※ `app/src/main/res/raw/shutter_soft.wav` はバイナリのため GitHub スナップショット
同期の対象外。設計書付録 A のスクリプト（numpy、乱数シード 0 固定）で決定的に
再生成できる。ローカルでビルドする場合は同スクリプトで生成して配置すること。

※ 初回確認（2026-11-13）: 9 項目中 8 項目は OK。「起動時のカメラ＝前面で
再起動しても前面で起動しない」不具合を v10 で修正。原因は collectAsState の
初期値（既定値）を実データと誤認して適用を打ち切っていたこと。DataStore の
最初の実データを collect して一度だけ適用するよう変更した。
v10 では項目 9 の「起動時のカメラ」のみ再確認する。

## Phase 6 の実機確認手順（Version 1.0）

### A. 画質比較（設計書 8.2）

同じ場所・同じ構図で、次の 3 通りで撮り比べる（可能なら手すりや机に固定して）。

- 純正カメラアプリ（OPPO 標準）
- Quiet Camera「標準」
- Quiet Camera「高画質」（Phase 6 で Camera2 Interop のノイズ低減・
  エッジ強調「高品質」を追加）

シーンは 4 つ： ①晴天の屋外（解像感・色・ダイナミックレンジ）
②逆光（白飛び・黒つぶれ） ③室内の暗所（ノイズ・色かぶり）
④2x ズーム（解像感の差）。

各シーンで「純正と比べてどうか」「標準と高画質で差があるか」を報告して
もらえれば、画質設定の最終値を確定する（差がなければ高画質の位置づけを
見直す）。

### B. 性能の目安（設計書 9.2）

- 起動 → プレビュー表示が体感 1.5 秒以内か
- シャッター音が離した瞬間に鳴るか（遅れて聞こえないか）
- 標準画質で、保存を待たずに連続撮影しても固まらないか

### C. 最終受け入れ（設計書 13 の残項目）

- バックグラウンドにするとカメラが解放される（他アプリでカメラが使える）
- 権限拒否・保存失敗でクラッシュしない
- ロック中の動作（撮影可・サムネイル/設定が開かない・消灯で終了）
